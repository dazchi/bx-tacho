# Icons

Source artwork for the OLED bitmaps in `main/icons.c`. Convert with
`tools/svg_icon_to_c.py` (the exact command for each icon is in `main/icons.c`).

| File | What | Origin |
|---|---|---|
| `battery-off.svg` | Low-battery screen | Tabler Icons "battery-off" (react-icons `TbBatteryOff`), MIT license, © Paweł Kuna. License text in `main/icons.c` |
| `beyblade.svg` | Project icon (boot screen, reusable elsewhere) | Original design for this project, generated by `tools/gen_beyblade_icon.py`. 24×24, monochrome (`currentColor`) |
| `beyblade-reference.jpg` | Design reference for `beyblade.svg` | AI-generated concept image (Google Gemini). Reference only, not used in the firmware |
